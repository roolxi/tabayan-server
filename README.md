# تبيّن

تبيّن يساعدك تتأكد من أي آية أو حديث بسرعة. تكتب جزء من النص أو تصف معناه، أو ترفع صورة أو مقطع، ويطلع لك النص من مصدره مع حكم المحدّثين.

بنيناه للمعرّفين بالإسلام والباحثين وصنّاع المحتوى، لأنهم يستشهدون بالنصوص كثيرًا ويحتاجون يتأكدون منها قبل النشر.

المشروع مشارك في تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي (مؤسسة باذل)، في مسار أدوات المعرفة والتحقق.

## جرّبه

- الموقع: https://tabayyan.duckdns.org
- تطبيق أندرويد: [Tabayyan.apk](https://github.com/roolxi/tabayan-server/releases/download/latest/Tabayyan.apk)
- تطبيق الآيفون: [Tabayyan.ipa](https://github.com/roolxi/tabayan-server/releases/download/latest/Tabayyan.ipa) (غير موقّع، يحتاج توقيع بأداة مثل Sideloadly قبل التثبيت)

## وش يسوي

- يبحث في القرآن والحديث بالنص، حتى لو اللفظ مو دقيق أو بدون تشكيل.
- يبحث بالمعنى: تكتب وصف الحديث بكلامك، ولو بالعامية، ويوصلك له.
- يعرض حكم المحدّث والراوي والكتاب لكل رواية، وينبّهك إذا اختلفت الأحكام.
- فيه عرض مبسّط، ووضع متخصص يعرض الروايات والتخريج كاملة.
- يستخرج الآيات والأحاديث من الصور والمقاطع، ومن روابط يوتيوب وتيك توك وإنستغرام (حتى ١٠ دقائق).
- متوفر على الويب والجوال.

## كيف يشتغل

1. المستخدم يكتب نص أو وصف، أو يرفع صورة أو مقطع أو رابط.
2. إذا كان المدخل صورة أو مقطع، يستخرج الذكاء الاصطناعي النص الديني منه. وإذا كان وصفًا بالمعنى، يحوّله لعبارات بحث.
3. نبحث في المصادر: القرآن من قاعدة محلية مبنية من مشروع تنزيل، والحديث من الموسوعة الحديثية في الدرر السنية.
4. السيرفر يطابق النتيجة ويعرضها مع مصدرها، أو يقول بوضوح إنه ما لقى شي.

نستخدم نموذج Gemini عن طريق OpenRouter (`google/gemini-3.5-flash-lite`، ومعه `gemini-2.5-flash` كاحتياط إذا تعطل الأساسي).

دور النموذج محصور في الفهم والاستخراج والاختيار. ما يكتب نص آية أو حديث، وما يحكم على حديث. في البحث بالمعنى، السيرفر يجيب نتائج حقيقية من الدرر، والنموذج يختار منها فقط، وأي نتيجة يرجعها من خارجها يرفضها السيرفر. وكل نص يُستخرج من صورة أو مقطع لازم يتطابق مع المصحف أو الدرر قبل ما يظهر للمستخدم.

## المصادر وكيف نتحقق منها

### القرآن الكريم

النص من [مشروع تنزيل](https://tanzil.net)، والملفات الأصلية موجودة في مجلد `source/`. اخترناه لأنه نص مراجع من مختصين ومتاح للاستخدام في التطبيقات بشرط ذكر المصدر.

ملف `build.py` يبني منه قاعدة `quran.sqlite`. النص اللي يشوفه المستخدم هو النص العثماني كما هو بدون أي تعديل. حذف التشكيل وتوحيد الهمزات نسويه في عمود البحث بس، عشان يلقى الآية حتى لو المستخدم كتبها بدون تشكيل.

نتائج التحقق من القاعدة محفوظة في `verification.json`: ١١٤ سورة و٦٢٣٦ آية، و١٢٤٧٢ مقارنة حرفية مع الملفات الأصلية، وفحص سلامة القاعدة، وبصمة SHA-256 للملفات الأصلية عشان نتأكد إنها ما تغيّرت. هذا تحقق إن الاستيراد ما غيّر شي من ملفات تنزيل، وليس مقارنة مع طبعة ثانية.

### الحديث وأحكام المحدّثين

من [الموسوعة الحديثية في الدرر السنية](https://dorar.net/hadith)، لأنها تجمع الأحاديث مع أحكام المحدّثين والتخريج، وهي مرجع معروف عند المتخصصين.

البحث يتم في تصنيفات الدرر الأربعة مع بعض: الأحاديث والأسانيد المحكوم عليها بالصحة، والأحاديث والأسانيد المحكوم عليها بالضعف. إذا طلع الحديث في تصنيف مقبول وتصنيف ضعيف بنفس الوقت، ننبّه المستخدم إن الأحكام مختلفة. والحكم يُعرض حرفيًا مثل ما هو في الدرر، مع الراوي والكتاب والتخريج ورابط الحديث.

وإذا ما لقينا نتيجة، نقول ذلك بوضوح، ونوضح إن عدم الظهور ما يعني إن الحديث موضوع.

## اختبرناه

جربناه على ٤١ نص: ٢٢ آية، و١٣ حديث بالنص، و٦ أوصاف بالمعنى. فيها نصوص بلفظ صحيح، ونصوص فيها أخطاء أو بدون همزات، وأوصاف بالعامية، ونصوص منتشرة ما لها أصل.

- وصل للنص الصحيح في ٣٩ من ٤١ (٩٥٪). الأحاديث كلها بالنص وبالمعنى ١٩ من ١٩، والآيات ٢٠ من ٢٢.
- متوسط الوقت على السيرفر: ١٫٤ ثانية للبحث بالنص، و٣٫٤ ثانية للبحث بالمعنى.
- ما ظهرت ولا نتيجة من خارج المصادر.

مثلًا «اطلبوا العلم ولو بالصين» طلع حكمه «باطل لا أصل له»، والوصف العامي «حديث إن الله ما يطالع أشكالكم يطالع قلوبكم» وصل لحديث «إن الله لا ينظر إلى صوركم...».

الاختبار كشف لنا كم شي نشتغل عليه:

- آيتين ما طلعت لأن المصحف يكتب «الزنى» والمستخدم يكتب «الزنا». نحتاج نوحّد الألف المقصورة في دالة `normalize`.
- في بعض الأحاديث المشهورة يطلع أول شي حكم على إسناد معيّن قبل الحكم العام، وهذا ممكن يلخبط غير المتخصص.
- تنبيه اختلاف الأحكام يعتمد على اللي ترجعه الدرر في كل طلب، فأحيانًا يظهر لنفس الحديث وأحيانًا لا.

## تشغيل السيرفر

تحتاج Python 3.11 أو أحدث، وFFmpeg، وNode.js (لبعض روابط الفيديو)، ومفتاح OpenRouter.

```sh
# تثبيت FFmpeg
sudo apt install ffmpeg          # Ubuntu / Debian
winget install Gyan.FFmpeg       # Windows
```

```sh
python -m venv .venv
source .venv/bin/activate        # على ويندوز: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

انسخ `.env.example` إلى `.env` وحط فيه مفتاح OpenRouter، وبعدها:

```sh
python server.py
```

وافتح http://127.0.0.1:8000.

لتشغيل الاختبارات: `pytest`

إذا كان السيرفر مثبت كخدمة على Linux:

```sh
sudo systemctl status tabayyan
sudo systemctl restart tabayyan
sudo journalctl -u tabayyan -f
```

## تطبيق الجوال

```sh
cd app
npm ci
npx expo start
```

لتغيير عنوان السيرفر، أضف في `app/.env`:

```env
EXPO_PUBLIC_API_BASE_URL=https://tabayyan.duckdns.org
```

تقدر تجرب الواجهة بـ Expo Go، لكن المشاركة من التطبيقات الثانية على أندرويد تحتاج نسخة APK. ملفات البناء في تبويب Actions.

## واجهات API

| الطلب | الوظيفة |
|---|---|
| `GET /api/health` | حالة السيرفر |
| `POST /api/quran/search` | البحث في القرآن |
| `POST /api/hadith/search` | البحث في الأحاديث |
| `POST /api/search/suggest` | اقتراح عبارات بحث بالمعنى |
| `POST /api/hadith/meaning-search` | البحث عن الأحاديث بالمعنى |
| `POST /api/media/extract` | استخراج النص من الصور والفيديو |
| `POST /api/media/url/jobs` | بدء معالجة رابط فيديو |
| `GET /api/media/url/jobs/{job_id}` | متابعة التقدم والنتيجة |

روابط الفيديو تُعالج من الويب عن طريق «الوسائط والروابط» ثم «ألصق رابطًا». الحد الافتراضي ١٠ دقائق، وتقدر تغيّره من `REMOTE_MEDIA_MAX_DURATION_SECONDS`. المهام محفوظة في الذاكرة، فشغّل عامل Uvicorn واحد بس ما لم تستخدم مخزن مهام مشترك.

## هيكل المشروع

- `server.py`: السيرفر
- `build.py` و`search.py`: بناء قاعدة القرآن والبحث فيها
- `services/`: الاتصال بالدرر والذكاء الاصطناعي ومعالجة الوسائط
- `source/`: ملفات تنزيل الأصلية
- `web/`: واجهة الويب
- `app/`: تطبيق الجوال (Expo)
- `tests/`: الاختبارات
- `.github/workflows/`: بناء تطبيقات الجوال

## التكلفة والاستمرار

التشغيل يحتاج خادم واحد وتكلفة استدعاءات النموذج، بحدود ٣٠ ريال شهريًا. القرآن محفوظ محليًا فما يعتمد على أي خدمة خارجية، والحديث يعتمد على الدرر. وخطتنا الجاية نعالج اللي كشفه الاختبار، ونسوي مراجعة دورية للنتائج مع مختص شرعي، وننشر التطبيق في المتاجر.

## بداية المشروع

قبل التحدي كان عندنا الفكرة ونموذج أولي على الويب يبحث بالنص في القرآن والحديث ويعرض الحكم من الدرر، بدون ذكاء اصطناعي.

خلال أيام التحدي (٤ إلى ٦ أكتوبر ٢٠٢٦) أضفنا استخراج النص من الصور والمقاطع، والبحث بالمعنى، والوضع المتخصص وتنبيه اختلاف الأحكام، وتطبيق الجوال، وروابط المنصات، وقسنا الدقة.
